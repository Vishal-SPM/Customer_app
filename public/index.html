Redemption

Two-step flow: validate first to get a temp auth ID, then redeem.

Acting Vendor

Select the vendor POS performing this redemption. Their API key is sent automatically.

Step 1
Validate Voucher

Operator scans QR or types the code. Returns benefit info and a temp auth ID (valid 10 min).

Validation result will appear here.
Step 2
Redeem Benefit

Use the temp auth ID from Step 1. Marks the voucher as redeemed.

Redemption result will appear here.
